# Support

**TEKA** — a next-generation technology platform: digital products, blockchain
infrastructure and immersive web experiences.
Live site: [teka-web-beta.vercel.app](https://teka-web-beta.vercel.app) ·
Whitepaper v1.0 on the site.

## Where to ask

| You need... | Go to |
|---|---|
| A bug or an issue with the site | [Open an issue](https://github.com/mhmdsdqi87-cloud/TEKA_web/issues) — with the page, browser and what you expected |
| A question about the ecosystem | [Telegram](https://t.me/TEKAOfficial) or [X](https://x.com/TEKAweb3) |
| Contributing code | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Setup and usage | [README](README.md) — Getting Started |

## Before you open an issue

1. Search [existing issues](https://github.com/mhmdsdqi87-cloud/TEKA_web/issues) first.
2. State the page/section, your browser and whether the ignition sequence had finished when it happened.
3. Screenshots help a lot for visual reports.

## Response expectations

The project is maintained by one person — there are no SLAs, but real reports
get real attention, usually within a few days.
