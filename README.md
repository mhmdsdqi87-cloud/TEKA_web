## ✨ Highlights

- 🚀 **Cinematic 8-second ignition sequence** — a space boot experience (VOID → SIGNAL → EMBLEM → CHARGE → WARP) that plays on every visit, with a discreet skip control and full `prefers-reduced-motion` support
- 🌌 **Living cosmos atmosphere** — canvas starfield with orbital drift, warp streaks and meteors, breathing nebula layers and vignette depth
- 🗺️ **Command Center** — a live mission-control dashboard for the TEKA ecosystem
- 🪙 **Honest tokenomics** — every figure sourced from Whitepaper v1.0; the only published contract is the Sepolia **testnet** deployment, clearly labeled. No invented data, no fake buttons
- ♿ **Accessible by design** — semantic HTML, ARIA labeling, keyboard navigation, skip-to-content
- ⚡ **Performance-first** — App Router, code splitting, GPU-friendly transforms only

## 🧬 Tech Stack

| Layer      | Technology                                    |
| ---------- | --------------------------------------------- |
| Framework  | Next.js 16 (App Router) + TypeScript 5        |
| UI         | Tailwind CSS 4 · shadcn/ui · Framer Motion    |
| State      | Zustand · TanStack Query                      |
| Database   | Prisma ORM (SQLite)                           |
| Fonts      | Space Grotesk · Inter · IBM Plex Mono         |

## 🚀 Getting Started

```bash
# install
bun install

# push the database schema
bun run db:push

# develop
bun run dev          # http://localhost:3000

# lint
bun run lint
```

## 📁 Structure

```
src/
├── app/                 # App Router — layout, metadata, SEO (sitemap, manifest)
│   └── api/             # Route handlers — stats, market, roadmap, presence…
├── components/
│   ├── teka/            # Platform views, navigation, preloader, atmosphere…
│   └── ui/              # shadcn/ui primitives
└── lib/teka/            # Brand config (single source of truth), router, hooks
```
